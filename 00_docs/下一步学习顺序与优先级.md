# 下一步学习顺序与优先级（结合当前在学 Qt）

> 本文件为**新增**，未修改任何已有文件。
> 背景：用户当前正**跟着视频学 Qt 基础**；目标 2027 寒假实习（工业软件/上位机/Linux C++ 方向）。
> 本文件只在"免重复学习分析"基础上，给出**接下来先碰哪块、按什么顺序**，避免边跟视频边跑偏。
> 时间基准：**2026-09-02**。

## 优先级总览（从高到低）

| 优先级 | 内容 | 为什么 |
|---|---|---|
| P0（当前） | **Qt 基础入门**（正跟视频）：布局/常用控件/信号槽/事件 | 你在学，别停；这是主线 |
| P0 | 同步**讲清原理**：Q_OBJECT、新式 connect、`const&`、事件系统 | 摸底证明你"会做不会讲"，原理要重点补 |
| P1 | **C++ 盲点补精准**：继承访问表、`weak_ptr`、`std::move`、虚析构、const 指针命名 | 面试高频 + 读 Qt 源码的钥匙；1-2 周内零散补 |
| P1 | **23 种设计模式**（重点：观察者/单例/工厂/装饰/代理/命令/组合/适配器） | 之前的缺口；在信号槽/事件处理解最自然 |
| P2 | **Qt 事件系统 + 文件与数据存储**（文件 IO、SQL、JSON） | 面试重点 + 项目必备；跟 Qt 基础往深走 |
| P3 | **1 个"上位机向"小项目**（串口调试 / 数据可视化 / 物联网监控面板 三选一） | 综合布局/控件/信号槽/文件/网络/线程的第一次实战 |
| P3 | **Qt 网络 + 多线程**（底层 socket 并行） | 为项目铺路，也是你的差异化优势 |
| P4 | **打包/Git/README/面试题整理** | 实习投递前的收尾 |

## 建议节奏（把省下来的时间用在这里）

1. **当下**：跟视频把 Qt 基础入门学完，每学一个功能，用两三句话讲清"它怎么实现、为什么"。
2. **随学随补**：过程中遇到"信号槽/事件/继承/智能指针"的"为什么"，就回头把 C++ 盲点补精准（不用单独整块学）。
3. **9-10 月**：设计模式 + Qt 事件系统 + 文件/数据（边学边做小 demo）。
4. **10-11 月**：选定 1 个上位机向项目开工（串口/数据可视化/物联网监控）。
5. **11-12 月**：Qt 网络 + 多线程，用进项目。
6. **12 月-1 月**：打包、Git、README、整理面试题。

## 关键提醒

- **别回去重学 C++ 主线基础**（已覆盖），只补 P1 那 5 个精准点。
- **"看视频 ≠ 会"**：每个功能都要能**跑起来 + 讲清原理**，否则不算完成。
- 现在跟视频学 Qt 是对的，重点是把"跟视频"变成"跟视频 + 动手 + 复述"。
