## 二、结论：**不用重复学习**的部分

- **C++ 主线基础**：C++ 基础、C++ 进阶（C++11）、数据结构、STL —— **已经学过，别重来**；只需把摸底暴露的 4-5 个弱项补精准（继承访问表、`weak_ptr`、`std::move` 本质、虚析构原因、const 指针命名）。
- **Qt 信号与槽** —— 你已做出可运行的登录项目，**不用重学**；只补理论表述（Q_OBJECT 作用、新式 connect 优点、`const&` 传参）。
- **Git 基础** —— 会用即可，不必系统重学。

## 三、真正要**新学**的部分（之前计划没有 / 还没做到）

1. **23 种常用设计模式**（你之前计划缺，面试高频、Qt 源码钥匙）
2. **Qt 事件系统**（面试重点，你还没碰）
3. **Qt 文件与数据存储**（SQL/JSON）、**网络编程**（底层 socket + Qt 网络）、**多线程**
4. 可选按方向取舍：**QML / 模型-视图 / Qt 高级特性 / Docker（打包）**

## 四、提醒（很重要）

- 你**现在正在学 Qt 基础，方向对**，别停下来重学 C++ 主线基础。
- 省下来的时间（本可以各种重复学的地方）**集中给**：设计模式 + Qt 事件系统 + 一个"上位机向"小项目。
- **"覆盖" ≠ "精通"**：摸底证明你会做信号槽、但讲不清原理。所以即便已覆盖的模块，也要在项目里做到"**能跑 + 能讲清为什么**"，才算真会。
