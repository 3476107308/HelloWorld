# 8 周试运行计划

## 目标

以 2027 年寒假获得第一段实习为短期目标，优先准备 Qt/C++ 客户端、工业软件、上位机和 Linux C++ 岗位，同时保留向嵌入式 Linux 和机器人软件发展的可能。

## 起点

- 当前从第 6 周开始，不重复第 1-5 周的完整学习流程。
- 已有基础：C++ 面向对象、STL、智能指针/RAII、C++11 部分特性、基础数据结构、基础 CMake、Ubuntu 基本命令、基础 Git、Qt 基础、OpenCV 课程学习。
- 需要通过实践补齐：CMake 工程化、GDB、Linux 编程、进程线程、Socket、多线程网络、Qt 工程、数据库和可展示项目。

## 8 周主题

| 周次 | 主题 | 必须产出 |
|---|---|---|
| 第 6 周 | C++ 进阶收尾与 CMake 工程化 | 多文件 C++ 项目、CMake 构建、基础 GDB 记录 |
| 第 7 周 | Linux 命令、编译流程与文件/进程基础 | Ubuntu 下可运行的 Linux 实验和命令笔记 |
| 第 8 周 | 进程、信号与基础多线程 | 父子进程、信号处理、线程同步实验 |
| 第 9 周 | 网络基础与 TCP/IP | TCP/UDP 流程笔记和网络诊断实验 |
| 第 10 周 | Linux Socket 编程 | TCP Echo Server/Client，支持 CMake 构建 |
| 第 11 周 | 多线程网络与消息协议 | 多客户端并发服务端，处理半包/粘包 |
| 第 12 周 | Qt Widgets、布局和信号槽 | 可运行的 Qt 客户端基础界面 |
| 第 13 周 | Qt 网络/线程/JSON 综合 | 设备监控项目的第一版 |

## 每周执行方式

- 每周单独生成 `WeekXX_Plan.md`。
- 每天完成 `example.cpp`、`exercise.cpp` 或项目功能，并提交运行结果。
- 完成后进行代码检查：编译错误、逻辑错误、内存/线程问题、工程结构和可解释性。
- 每周末完成一个可运行验收产物和 `week_note.md`。
- 根据实际进度调整后续周计划，不机械追赶原定日期。

## 时间分配

- 每周至少 15 小时。
- 学习资料和原理：约 6 小时。
- 独立编码、调试和项目：约 7 小时。
- 面试题、算法和英语：约 2 小时。

## 试运行结束判断

8 周后根据以下证据调整路线：

1. 是否能在 Ubuntu 下独立用 CMake 构建多文件 C++ 项目。
2. 是否能解释并调试进程、线程、Socket 和基本同步问题。
3. 是否完成至少一个可展示的 Qt/Linux 综合项目。
4. 是否愿意继续投入 Qt/Linux，或开始购买开发板并把嵌入式提高为主线。
