## 〇、先解决最大的实操问题：命令行参数怎么在 IDEA 里传？

教材写的是 `java Say 妈妈 我爱你!!!`——那是**在终端里**的用法。在 IDEA 里点绿三角运行时，参数要填到**运行配置**里：

1. 先正常运行一次（`Shift+F10`）让 IDEA 生成运行配置；或者直接点右上角运行配置下拉 → **`编辑配置...`**
2. 在弹出的窗口里找到 **「程序参数」**（英文是 `Program arguments`）
3. 把参数按空格分隔填进去：`妈妈 我爱你!!!`
4. 「确定」→ 再 `Shift+F10`，这次就带上参数了

> ⚠️ 如果参数本身含空格，要用双引号包起来，例如 `"张 三" 你好`。
> **想体验"命令行参数"的本意**，也可以在 IDEA 底部「终端」里手动跑：
> ```powershell
> cd out\production\Lab01
> java Say 妈妈 我爱你!!!
> ```
> （注意中文可能在终端里显示成乱码，先执行 `chcp 65001` 会好些；IDEA 的运行窗口不存在这个问题，因为它会带 `-Dfile.encoding=UTF-8`）

**为什么叫"命令行参数"**：程序启动时由操作系统交给 `main` 的那串字符串。C++ 里是：

```cpp
int main(int argc, char* argv[])   // argv[0] 是程序名本身，argv[1] 才是第一个参数
```

Java 里是：

```java
public static void main(String[] args)   // args[0] 就是第一个参数，没有 argc
```

**关键差异**：
- Java **没有 `argc`**，用 `args.length` 取个数；
- Java 的 `args[0]` **就是第一个参数**（不像 C++ 的 `argv[0]` 是程序名）；
- Java 的 `main` 必须是 `void`，所以退出码要用 `System.exit(1)` 表示（C++ 是 `return 1`）。

### ⚠️ 别把"命令行参数"和"标准输入"搞混（C++ 选手高频疑问）

| | **命令行参数** | **标准输入** |
|---|---|---|
| C++ | `main(int argc, char* argv[])` 的 `argv` | `std::cin >> x` / `scanf` |
| Java | `main(String[] args)` 的 `args` | `Scanner sc = new Scanner(System.in); sc.nextInt();` |
| **谁在什么时候提供** | **启动程序那一刻**，由操作系统/启动器**一次性**传入 | **程序运行过程中**，由用户或管道**逐次**送入 |
| **会阻塞吗** | ❌ 不会——启动前就定好了，拿不到就是数组短 | ✅ 会：读的时候缓冲区没数据就一直等 |
| 本实验用哪个 | ✅ 用这个 | ❌ 不用 |

**所以"要不要写 `cin`"的答案是：不用写，本题也不需要任何读取语句。** 输入在**启动时**就已经交给程序了；参数不够不是"在等输入"，而是"`args` 数组长度为 0"，所以直接判断 `args.length` 即可。

> 补充：`cin` 本身也不是"会阻塞"——是**调用读取操作时**才阻塞。不写读取语句，C++ 程序同样一路跑完。
> （将来用 Java 读标准输入时注意：`Scanner` 很慢，竞赛里通常用 `BufferedReader` + `StringTokenizer`。）

## 任务2-① P146 第4题：命令行参数（`Say.java`）

**要求**：编写程序，运行程序时带命令行参数，体会命令行参数的作用。不带参数时会出现异常，要在程序中判断。

```java
public class Say {
    public static void main(String args[]) {
        if (args.length < 2) {                    // ← 教材第 (4) 步要求加的保护
            System.out.println("需要 2 个命令行参数!");
            System.exit(1);                       // 相当于 C++ 的 return 1
        }
        String name = args[0];
        String word = args[1];
        System.out.println("我想对" + name + "悄悄地说:" + word);
    }
}
```

**实测输出**（`java Say 妈妈 我爱你!!!`）：
```
我想对妈妈悄悄地说:我爱你!!!
```

**实测异常**（删掉那个 `if` 后不带参数运行，就是教材第 (4) 步说的"异常"）：
```
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException:
    Index 0 out of bounds for length 0
        at SayNoGuard.main(SayNoGuard.java:4)
```
> 📌 **和教材不一样是正常的**：老 JDK 只打印 `ArrayIndexOutOfBoundsException: 0`，JDK 9 以后会附带 `Index 0 out of bounds for length 0` 这种详细信息。你写报告时按**你屏幕上实际显示的**写。

**⚠️ 教材的笔误**：第 (4) 步写的是 `public class say`（小写 s），但文件名是 `Say.java`。Java 规定 **public 类名必须和文件名完全一致（大小写敏感）**，所以必须写 `class Say`，否则报错：
```
错误: 类 say 是公共的, 应在名为 say.java 的文件中声明
```

**C++ 对照**：`args` ≈ `argv`（但少了 `argv[0]` 那个程序名），`args.length` ≈ `argc`，`System.exit(1)` ≈ `return 1`。

## 任务2-② P146 第5题：命令行参数求三数最大值（`Max.java`）

```java
public class Max {
    public static void main(String args[]) {
        int max;
        int a = Integer.parseInt(args[0]);     // 字符串 → int，≈ C++ 的 std::stoi / atoi
        int b = Integer.parseInt(args[1]);
        int c = Integer.parseInt(args[2]);

        if (a > b && a > c)
            max = a;
        else if (b > c)
            max = b;
        else
            max = c;

        System.out.println("三个数中最大的是:" + max);
    }
}
```

**实测输出**（`java Max 23 45 34`）：
```
三个数中最大的是:45
```
**边界实测**：`5 5 3 → 5`、`1 2 3 → 3`、`-5 -2 -9 → -2`、`1000000 999999 1000000 → 1000000`（含相等、负数都正确）

**Java 特有陷阱**：
- `Integer.parseInt("abc")` 会抛 `NumberFormatException`（不像 C++ 的 `atoi` 静默返回 0）——**Java 宁可炸也不给你一个悄悄错误的数**，这是它的设计哲学；
- 参数不足 3 个 → `ArrayIndexOutOfBoundsException`。**建议你顺手加上 `if (args.length < 3)` 保护**（加分项，也呼应上一题的考点）。

## 任务3 P149 第1题：变量定义与数据类型（`SimpleTypes.java`）

> ⚠️ **教材原文有一处编译错误**：`char c="c";` 用了**双引号**。Java 里双引号是 `String`，`char` 必须用**单引号** `'c'`。这是本题唯一需要改的地方。

```java
import java.io.*;                    // 其实本题用不到，教材习惯性加的，IDEA 会把它标灰

public class SimpleTypes {
    public static void main(String args[]) {
        byte b = 055;                // 八进制（前导 0）→ 十进制 45
        short s = 0x55ff;            // 十六进制 → 十进制 22015
        int i = 1000000;
        long l = 3615L;              // L 后缀表示 long
        char c = 'c';                // ← 教材写成了 "c"，必须改成 'c'
        float f = 0.23F;             // F 后缀表示 float
        double d = 0.7E-3;           // 科学计数法
        boolean bool = true;

        System.out.println("b=" + b);
        System.out.println("s=" + s);
        System.out.println("i=" + i);
        System.out.println("l=" + l);
        System.out.println("c=" + c);
        System.out.println("f=" + f);
        System.out.println("d=" + d);
        System.out.println("bool=" + bool);
    }
}
```

**实测输出**：
```
b=45
s=22015
i=1000000
l=3615
c=c
f=0.23
d=7.0E-4
bool=true
```

**C++ 对照与关键差异**：

| 写法 | C++ | Java |
|---|---|---|
| `055` / `0x55ff` | 一样是八进制 / 十六进制 | ✅ 完全一样 |
| `3615L` | 一样 | ✅ 一样 |
| `0.23F` | C++ 写 `float f = 0.23;` **能编译**（隐式收窄） | ❌ **Java 编译不过**，必须写 `0.23F`（Java 不允许 double 隐式转 float） |
| `'c'` vs `"c"` | `'c'` 是 char，`"c"` 是 `const char*` | `'c'` 是 char，`"c"` 是 `String`——**两者毫无关系，不能互转** |
| `char` 的大小 | 8 位（通常） | **16 位无符号**，存的是 UTF-16 码元，能直接放中文 `char ch='中';` |
| `boolean` | `bool` | `boolean`（只有 `true`/`false`，**不能和 int 互转**，`if(1)` 不合法） |

> 💡 为什么 Java 强制 `0.23F`？因为 Java 的原则是"**有精度损失就必须显式写出来**"（要收窄就 `(float)0.23` 或加 `F`）。这和它"宁可报错也不给悄悄出错的数"是同一个哲学。

## 任务4 P150 第2题：算术运算（`ArithmeticOp.java`）

```java
import java.io.*;

public class ArithmeticOp {
    public static void main(String args[]) {
        int a = 5 + 4;
        int b = a * 2;
        int c = b / 4;
        int d = b - c;
        int e = -d;
        int f = e % 4;
        double g = 18.4;
        double h = g % 4;
        int i = 3;
        int j = i++;
        int k = ++i;

        System.out.println("a=" + a);   // 9
        System.out.println("b=" + b);   // 18
        System.out.println("c=" + c);   // 4   ← 整数除法截断
        System.out.println("d=" + d);   // 14
        System.out.println("e=" + e);   // -14
        System.out.println("f=" + f);   // -2  ← 余数符号跟随被除数
        System.out.println("g=" + g);   // 18.4
        System.out.println("h=" + h);   // 2.3999999999999986 ← 浮点误差
        System.out.println("i=" + i);   // 5
        System.out.println("j=" + j);   // 3   ← 先赋值后自增
        System.out.println("k=" + k);   // 5   ← 先自增后赋值
    }
}
```

**实测输出**（逐行核对）：
```
a=9
b=18
c=4
d=14
e=-14
f=-2
g=18.4
h=2.3999999999999986
i=5
j=3
k=5
```

**四个必须理解的输出**：

| 变量 | 值 | 为什么 |
|---|---|---|
| `c` | **4** | `18/4` 两个 `int` 相除 → **整数除法截断**（和 C++ 一样，不四舍五入） |
| `f` | **-2** | `-14 % 4`：Java 的 `%` 结果**符号跟随被除数**（-14%4=-2）。C++11 起也是这个规则，所以你应该有印象 |
| `h` | **2.3999999999999986** | `18.4 % 4` 是**浮点取余**（C++ 的 `std::fmod`）。因为 18.4 在二进制里无法精确表示，结果不是干净的 2.4。**这不是 Java 的 bug，是 IEEE 754 的必然结果** |
| `i/j/k` | 5 / 3 / 5 | `j=i++` 先取值再自增（j=3,i=4）；`k=++i` 先自增再取值（i=5,k=5）——**和 C++ 完全一样** |

> 💡 写报告时，"h 为什么是 2.3999999999999986"是个很好的分析点：**浮点数不能精确表示十进制小数**。想输出好看就用 `System.out.printf("h=%.2f%n", h);`（`%n` 是 Java 的换行符，等价于 C 的 `\n`，但跨平台更安全）。

## 任务5 P8 例2.1.3：数组赋值与打印（`ArrayRefer.java`）

```java
public class ArrayRefer {
    public static void main(String args[]) {
        int i;
        int arrayA[] = new int[5];              // 教材写法（等价于 int[] arrayA = new int[5];）
        for (i = 0; i < 5; i++)
            arrayA[i] = i;
        for (i = 0; i < arrayA.length; i++)     // length 是"字段"，不是函数：不要写 length()
            System.out.println("arrayA[" + i + "]=" + arrayA[i]);
    }
}
```

**实测输出**：
```
arrayA[0]=0
arrayA[1]=1
arrayA[2]=2
arrayA[3]=3
arrayA[4]=4
```

**C++ 对照与差异**：

| 话题 | C++ | Java |
|---|---|---|
| 声明 | `int a[5];`（栈数组） | **必须** `int[] a = new int[5];`（**堆上的对象**，a 是引用） |
| 长度 | 没有，要自己传 | `a.length`（**字段，不能加括号**） |
| 默认值 | 不初始化就是垃圾值（UB 温床） | **自动清零**：`new int[5]` 全是 0 |
| 越界 | 未定义行为（可能崩、可能静默改内存） | **抛 `ArrayIndexOutOfBoundsException`**，并告诉你下标多少、长度多少 |
| 释放 | `delete[]` / RAII | 不用管，**GC 自动回收** |

> 🔑 对打过蓝桥杯的你来说，这张表里最爽的一条是：**Java 没有未定义行为**。数组越界一定报错、不会静默改掉别的内存——调试时能省很多时间。代价是**速度慢一些、内存占用大一些**。

## 任务6 P153 编程题第1题：圆周长与面积（`Circle.java`）

**要求**：编写一个 Java 程序，计算半径为 3.0 的圆的周长和面积，并输出计算结果。

```java
public class Circle {
    public static void main(String args[]) {
        double r = 3.0;
        double pi = Math.PI;                     // 3.141592653589793（也可按教材写 3.14159）

        double circumference = 2 * pi * r;       // 周长 = 2πr
        double area = pi * r * r;                // 面积 = πr²

        System.out.println("半径 r = " + r);
        System.out.println("周长 = " + circumference);
        System.out.println("面积 = " + area);

        // 想要"固定小数位"，用 printf（和 C 的 printf 一样）
        System.out.printf("周长 = %.4f%n", circumference);
        System.out.printf("面积 = %.4f%n", area);
    }
}
```

**实测输出**：
```
半径 r = 3.0
周长 = 18.84955592153876
面积 = 28.274333882308138
周长 = 18.8496
面积 = 28.2743
```

**C++ 对照**：`Math.PI` ≈ `M_PI`；`System.out.printf("%.4f%n", x)` ≈ `printf("%.4f\n", x)`。
（想用 `3.14159` 也可以，结果会是 `18.84954` / `28.27431`——**报告里写清楚你用的是哪个值**即可。）

## C++ → Java 速查（本题集涉及的部分）

| 功能 | C++ | Java |
|---|---|---|
| 入口 | `int main(int argc, char* argv[])` | `public static void main(String[] args)`（**必须 void**） |
| 输出换行 | `printf("...\n")` / `cout << ... << endl` | `System.out.println(...)`；或 `System.out.printf("%.4f%n", x)` |
| 字符串拼接 | `std::string` 的 `+` / `<<` | **任何类型 `+` String 都变成字符串**（`"i="+i`） |
| 字符串转整数 | `atoi` / `std::stoi` | `Integer.parseInt(s)`（失败抛异常，不返回 0） |
| 退出码 | `return 1` | `System.exit(1)` |
| 数组 | `int a[5];` | `int[] a = new int[5];`，长度用 `a.length` |
| 常量 | `const` / `constexpr` | `static final`（`final` 只表示"不可再赋值"） |
| 内存 | `new/delete`、RAII | 只管 `new`，**GC 自动回收** |
| 整数溢出 | 未定义行为 | **环绕**（`int` 溢出会变成负数，可预测） |
| 布尔 | `bool`，可隐式转 int | `boolean`，**不能和数字互转**，`if(1)` 非法 |
