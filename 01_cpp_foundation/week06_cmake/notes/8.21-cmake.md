# cmake学习
## cmake指令敲写
cmake_minimum_required(VERSION x) 需要至少版本至少为x的CMake工具
project(name LANGUAGES CXX) 定义项目名称 并声明项目使用c++
add_executable(file
    src/main.cpp
    src/calculator.cpp
) file是目标名称 也是添加的可执行文件的名称 并且需要将所有要参与编译的源文件全部写进去 使用制定的源文件，在项目中添加一个可执行文件
target_include_directories(目标名 PRIVATE 目录) 将包含的目录名添加到指定的目录中 而且添加的目录必须是通过add_executable()或者add_library()添加进来的
## cmake命令行工具
cmake --build <dir> 指定构建dir这个目录
